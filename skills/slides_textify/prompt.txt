`inputs/slides.pdf`에서 각 페이지의 **anchor 텍스트**를 추출해 `outputs/pages.json`으로
저장합니다. 목표는 페이지별로 "이 슬라이드가 강의 안에서 어떤 위치/주제인지"가
드러나는 키워드를 뽑는 것. 이 결과는 나중에 녹취록과 alignment할 때 anchor로 쓰임.

# 사전 처리

`python scripts/extract_pdf.py inputs/slides.pdf -o _raw` 를 실행하면
`_raw/page_001.txt`, `_raw/page_002.txt`, ... 가 생성됨.

# 페이지별 분석

각 `_raw/page_NN.txt`를 읽고 다음을 추출:

- **title**: 슬라이드 제목. 명시된 제목이 있으면 그대로, 없으면 내용 첫 줄 또는
  핵심 주제를 한 줄로 요약.
- **anchors**: 이 페이지의 핵심 키워드 리스트 (3~8개). 전문용어, 고유명사,
  핵심 개념. 이 키워드들은 녹취록 매칭에 쓰이므로 **일반어/일상어는 제외**,
  이 슬라이드가 다루는 특정 주제 식별자가 되는 단어들만.
- **brief**: 이 슬라이드의 강의 내 위치와 주제를 한 문장으로 (30자 내외).
  예: "TCA 회로 전체 개요를 보여주는 도식" / "NADH 생성 단계의 효소 설명".
  그림/도표/수식이 있으면 "막대 그래프로 ... 비교" 수준의 한 줄 묘사만 포함.

페이지가 표지·목차·참고문헌처럼 내용이 거의 없으면 title만 채우고 anchors는
빈 배열, brief는 해당 페이지의 성격을 간단히 기술.

# 출력

최종 결과를 `outputs/pages.json`에 저장. 다음 형식:

```json
{
  "pages": [
    {
      "index": 1,
      "title": "...",
      "anchors": ["...", "..."],
      "brief": "..."
    },
    ...
  ]
}
```

페이지 번호는 1부터. 순서대로 `index` 증가. 추출된 모든 페이지에 대해 항목 생성.

언어는 원본 슬라이드의 언어를 따름 (한국어 슬라이드면 한국어로).
